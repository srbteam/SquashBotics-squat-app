Squat app (installable web app)

Put this folder online over HTTPS (GitHub Pages is free), open the address in Safari on iPhone,
tap Share, then Add to Home Screen. It installs with the Squat icon, opens full screen, and works offline after the first open.

GitHub Pages: new repo -> upload every file in this folder (keep the icons/ folder) -> Settings -> Pages ->
Source: Deploy from a branch, branch main, folder / (root) -> Save. The address appears at the top of that page after a minute.
